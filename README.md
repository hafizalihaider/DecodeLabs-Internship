# Decode Labs Cyber Security Internship

A collection of practical cybersecurity projects developed during my **Cyber Security Internship at Decode Labs**.

This repository contains four Python-based projects focused on authentication security, data protection, phishing awareness, and Windows system security assessment.

---

## Projects

### 01. Password Strength Checker

A Python-based tool designed to evaluate the strength of passwords according to basic security requirements.

**Checks include:**

* Password length
* Uppercase and lowercase characters
* Numbers
* Special characters
* Character-type count
* Sequential patterns
* Overall password strength

**Result:** Classifies passwords as **Weak, Medium, or Strong**.

---

### 02. Basic Encryption & Decryption

A Python project demonstrating the basic concepts of protecting information through encryption and recovering it through decryption.

**Features include:**

* Text encryption
* Text decryption
* User input handling
* Basic cryptographic concepts
* Menu-based interaction

The project provides practical understanding of how plaintext can be transformed into protected ciphertext and later restored.

---

### 03. Phishing Awareness Analyzer

A Python-based cybersecurity awareness tool designed to analyze sample emails and identify potential phishing indicators.

**Features include:**

* Email analysis
* Suspicious-content identification
* Phishing awareness checks
* Categorization of sample emails
* Organized output for analyzed emails

The project focuses on helping users recognize common characteristics of phishing emails and improve email security awareness.

---

### 04. System Vulnerability Checklist

A Python-based Windows security assessment tool that checks common system and user-security configurations.

**Security checks include:**

* Password policy
* Installed software
* Software approval
* Software update status
* Multi-Factor Authentication (MFA) indicators
* Screen-lock configuration
* User account privileges
* Windows Firewall status

The project uses **Python, PowerShell, and Windows security commands** to collect system information and provide security assessments such as **PASS, WARNING, and REVIEW**.
